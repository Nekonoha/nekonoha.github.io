# 新デザイン（redesign）

いまのサイトと同じ内容を、別のデザインで組み直したものです。データはいまのサイトのファイルをそのまま読むので、Actions の毎日の取り込み（TuneCore・pixiv・BOOTH）と小説の追加が、そのまま反映されます。

公開しているサイト（nekonoha.github.io）は、この新デザインです。Actions が毎日、取り込みのあとに `build.mjs` で書き出して公開します。前のサイト（`frontend/` の Nuxt）に戻す方法は、下の「公開の切り替え」にあります。

## 手元で見る

npm の準備はいりません（Node.js だけで動きます）。

```powershell
cd C:\Users\tanfa\Documents\working\nekonoha.github.io
node redesign/serve.mjs
```

http://localhost:5180 を開きます。止めるときは Ctrl+C。ポートを変えるときは `$env:PORT=5190; node redesign/serve.mjs`。
ファイルを開くたびに読み直すので、小説を足したりデータを更新したりしたあとは、ページを再読み込みするだけで反映されます。
タイトルなどの文字は Google Fonts から読むので、ネットにつながっている必要があります。

## 公開用の書き出し

```powershell
node redesign/build.mjs
```

`redesign/dist/` に、GitHub Pages にそのまま置けるファイルができます（Git には入れません）。

- 作品の一覧（`api/site.json`）と、小説の各話の本文（`api/novels/<作品>/<話>.json`）
- 画像（`frontend/public/images` をコピー）
- いまのサイトの URL からの案内。`/trial`、`/unrequited`、`/about`、`/works`、`/novels`、`/novels/<作品>`、`/novels/<作品>/<話>` に来た人を、新しいページへ移します。X などに貼られた古いリンクも切れません。
- `404.html`、`sitemap.xml`、`robots.txt`

## 公開の切り替え

`.github/workflows/deploy.yml` の `SITE` で、どちらのデザインを公開するかを決めます。

- `redesign`：新デザイン（いまの設定）
- `nuxt`：前のサイト

前のサイトに戻す方法は2つあります。

1. **ファイルを変える**：`deploy.yml` の `SITE: ${{ vars.SITE || 'redesign' }}` の `'redesign'` を `'nuxt'` にして push する。
2. **GitHub の画面で変える**：リポジトリの Settings → Secrets and variables → Actions → Variables に、名前 `SITE`、値 `nuxt` の変数を作り、Actions の「Run workflow」で実行する。新デザインに戻すときは変数を消す。

前のサイトを公開している間も、Actions は毎回新デザインを書き出して、壊れていないか確かめます（そのときは、書き出しに失敗しても公開は止まりません）。

## できること

- **作品の色がページににじむ**：見ているセクションや、音楽の棚で選んだジャケットの色が、背景と強調色にゆっくり移ります。
- **音楽の棚**：ドラッグ、矢印キー、クリック、スワイプで送れます。真ん中の1枚に試聴（Spotify）と配信へのリンク。
- **探す（Ctrl+K または /）**：商品、曲、ゲーム、イラスト、小説の各話、セクションをまとめて探せます。日本語と英語のどちらの名前でも引けます。
- **セクションの移動**：マウスのPCでは左端に浮かぶアイコンの目次（乗せると名前が出る。画面が広いときはいつも名前つき）。いまのセクションに色の札が付き、札の下の線が読み進めた分だけ伸びます。スマホとタブレットでは画面の下。移動すると見出しがバーのすぐ下に来ます。
- **いちばん上へ**：少しスクロールすると右下に出ます。まわりの輪がページの進み具合。
- **言語**：上のバーの「EN / JA」で切り替え。選んだ言語はブラウザに保存されます。初めての人は、ブラウザの言語が日本語なら日本語、それ以外は英語。`?lang=en` を付けた URL でも英語で開けます。BOOTH の商品名は「日本語名 / English name」の形なら英語名を、カテゴリは英語名を出します。小説の本文、曲名・イラストの題名などの中身は元のままです。
- **ゲームのページ**：題名、画面写真、ダウンロード（英語表示では英語版を先に）、遊び方、スクリーンショット、操作方法。
- **小説**：目次（章ごと）、続きから、話数を入れて移動、読んだ位置の保存。
  - **スクロールで読む**（はじめの設定）：1枚の長い紙を下へ読み進める。次の話へ移るときは、いまの紙が左へ引き抜かれて、下に重なっていた次の話の紙が出てくる。前の話へは、前の話の紙が左から滑ってきて重なる（→/←キー、下の「次の話」、読書バーの矢印、紙の右下の折り返し）。スマホでは左へなぞると紙が指についてきて、下に次の話の紙が見える。離すと次の話へ。右へなぞると前の話の紙が出てくる。
  - **ページで読む**：紙の本のように1ページずつ（広い画面は見開き）。右の紙が背を軸に立体的にめくれる。
  - 設定（Aa のボタン）：めくり方（スクロール・ページ）、紙（自動・白・生成り・夜。自動はサイトの明るさに合わせる）、文字の大きさ、行間、書体。
- 明るい表示と暗い表示。動きを減らす設定にしているときは、アニメーションを止めます。

## ファイル

| ファイル | 中身 |
|---|---|
| `public/index.html`・`style.css`・`app.js` | 画面（依存なし。画面はハッシュ `#/…` で切り替え） |
| `content.mjs` | ゲームの説明・プロフィール・リンク（日本語と英語）。ここだけは手で直す |
| `site-data.mjs` | `frontend/` のデータと小説を読んで、画面に渡す形にまとめる |
| `serve.mjs` | 手元で見るためのサーバー |
| `build.mjs` | 公開用の書き出し |

## URL

| URL | 画面 |
|---|---|
| `/#/` | トップ |
| `/#/shop`・`/#/music`・`/#/games`・`/#/art`・`/#/novels`・`/#/about` | トップの各セクション |
| `/#/game/trial`・`/#/game/unrequited` | ゲーム |
| `/#/novel/<作品>` | 小説の目次 |
| `/#/novel/<作品>/<話>` | 小説を読む |
